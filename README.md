## Descripción del Proyecto
Mashka Box Training Club es un sitio web desarrollado para un centro de entrenamiento funcional y CrossFit ubicado en Latacunga, Ecuador.

El objetivo del sitio es mostrar información sobre:
- Servicios y beneficios del gimnasio.
- Horarios de atención.
- Planes de entrenamiento.
- Información de contacto.
- Ubicación del establecimiento.

También incluye contenido multimedia como imágenes y videos relacionados con los entrenamientos e instalaciones.
